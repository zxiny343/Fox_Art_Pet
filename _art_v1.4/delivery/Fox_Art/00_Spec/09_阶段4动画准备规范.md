不是"示意图"。所有坐标、关键帧都是机读 JSON，数值来自 v3.0 实测锚点。

## 3. 动作库（36 个，超出 20+ 要求）

| 分组 | 动作 |
|---|---|
| 待机（5） | `idle_breath` 呼吸待机 · `idle_tail_sway` 尾巴轻摆 · `idle_ear_twitch` 耳朵抖动 · `blink` 眨眼 · `idle_look_around` 左右张望 |
| 移动（6） | `walk` 行走 · `walk_fast` 快走 · `run` 奔跑 · `jump` 起跳 · `land` 落地 · `fall` 下落 |
| 姿态（6） | `sit_down` / `sit_idle` / `stand_up` / `lie_down` / `sleep` / `wake_up` / `stretch` |
| 情绪（7） | `happy_wag` 摇尾 · `happy_bounce` 蹦跳 · `nod` 点头 · `shake_head` 摇头 · `tilt_head` 歪头 · `sad_droop` 垂头 · `angry_puff` 炸毛 |
| 互动（8） | `scratch` 挠痒 · `roll_over` 打滚 · `play_bow` 邀玩 · `howl` 嚎叫 · `bark` 吠叫 · `eat` 进食 · `drink` 喝水 · `pet_response` 被抚摸 |
| 系统（4） | `drag` 被拖拽 · `drop` 掉落 · `sparkle` 升级/变异闪光 |

每个动作含：`frames` / `durationSec` / `loop` / `layer` / `priority` /
`channels[{bone, channel, keys[[t, value, curve]]}]` / `slots[{slot, keys}]`。

**通道单位**：`rotate` = 度，`translate` = 母版像素（1024 基准），
`scale` = 比例（1.0 = 原尺寸），`t` = 归一化时间 0..1。

**分层**：`base` 独占基础姿态；`add` 可与 base 叠加（尾巴摆 / 耳抖）；
`face` 表情层，优先级最高（眨眼不被待机覆盖）。

**循环动作的首尾已对齐**（正弦通道在 t=0 与 t=1 同相位），可直接 loop 不跳帧。

## 5. Spine 2D 映射表

| 本规范 | Spine 概念 |
|---|---|
| bone | bone（按 `parent` 建层级，`start` 即骨骼原点） |
| slot | slot（挂在对应 bone 上，`anchor` 即附件定位点） |
| 部件 PNG | attachment（region），文件名即 attachment 名 |
| `channels[].channel=rotate` | bone timeline: rotate |
| `scaleX/scaleY` | bone timeline: scaleX/scaleY |
| `translateX/Y` | bone timeline: translateX/Y |
| `slots[].keys` | slot timeline: attachment（0 帧步进，不插值） |
| `layer=add` | track 1+（track 0 放 base） |
| `priority` | track 序号 / 混合权重 |

导出建议：Spine 的 `.json` 里 bone 的 `x/y` 用 `start`（需转成相对父骨的偏移），
`rotation` 用 `restRotationDeg`；附件坐标用 `anchor` 相对所属 bone。

## 6. 已知限制（不掩饰）

1. **骨骼坐标来自静态 3/4 站姿实测**，不是真实绑定权重。导入 Spine 后仍需逐部件刷权重，
   尤其是 `body` 的呼吸缩放会让腹部/腿根出现轻微拉伸，需要权重补偿。
2. **36 个动作的关键帧是程序生成的正弦/斜坡曲线**，用于"能跑起来 + 节奏正确"，
   不是手 K 的最终品质。走路/奔跑建议后续按参考视频手调相位。
3. **耳朵/尾巴极限性状的骨骼长度不同**：长尾用 4 段链、短尾只需 2 段，
   导入时按尾型选择链条长度，不要强行复用 4 段（否则短尾会被拉变形）。
4. **表情件是程序化绘制**（眉/嘴/闭眼），风格已对齐描边色与笔触，
   但精细度低于母版 AI 原画。若要更高品质，可用同一套锚点重画。
5. `muzzle` 骨骼只挂嘴插槽，鼻子是 body_core 的一部分，不可单独动。
