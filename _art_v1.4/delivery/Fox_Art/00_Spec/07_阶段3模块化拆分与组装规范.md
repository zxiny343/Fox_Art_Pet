## 一、这一阶段真正解决的问题

| 问题 | 现象 | 根因 | 解法 |
|---|---|---|---|
| 部件形状不配套 | 换装后露出硬边矩形色块，8/8 个体全中 | 阶段 2 的耳/尾来自**隔离白底部件表**，是"毛绒道具"形状，与母版尾巴不配套 | 改用**图生图从母版生成同姿态变体**，再用同一 mask 切出 → 天然配套 |
| socket 补色变黑 | 整只变成近黑剪影 | 补色从**描边像素**扩散，描边是深色 | 补色源排除描边像素，改用体色扩散 + 原部件模糊混合 |
| 10 套毛色全黑 | 除霜蓝与曜金外 8 套 RGB≈0 | `recolor_coat` 权重归一化被写进 `if role_masks:` 分支，无 pointsRule 的配色权重和 ≫1 | 归一化改为无条件执行 |
| 花纹盖住五官 | 身体糊成一片、五官消失 | ① 遮罩信息在 **alpha 通道**却按 RGB 读取 ② 花纹在眼睛**之后**叠加 | 改读 alpha 通道，并把花纹移到耳/眼之前 |

## 三、socket 补色系统（关键设计）

**问题**：挖空区必须 ≥ 原部件（否则换装后原部件残留），但小部件（小耳/短尾）盖不满挖空区 → 露出透明洞。

**解法**：挖空区不做透明，用 socket 层补色。

```
socket_rgb = 0.5 × gaussian_blur(原部件, σ=6) + 0.5 × 毛色 base
填充源 = 非描边像素的最近邻扩散（描边像素被排除）
```

**踩过的坑**：第一版从全部像素（含描边）扩散，挖空区被填成近黑色，33% 面积变黑 → 整只变剪影。必须排除描边。

## 四、部件配套化（阶段 3 的核心改造）

阶段 2 的独立部件覆盖率实测仅 **39%–52%**（`diag_coverage.py`），因此全部替换为配套部件。

**生成方式**：以阶段 1 母版为参考图做 image_to_image，只改尾/耳形状，其余强制一致；出图后按母版包络规整，再用**同一套 split_regions mask** 切出。

**两种对齐模式**（下游必须区分）：

| 模式 | 部件 | 组装方式 |
|---|---|---|
| `aligned-full-canvas` | 阶段 3 配套耳/尾 | 1024×1024 全画布，**直接 `(0,0)` alpha_composite**，零错位、无需锚点换算 |
| `anchored-legacy` | 阶段 2 眼件/瞳孔/独立件 | 按 `rootPointInCanvas` 对齐锚点 + 主轴旋转 + 母版实测尺寸归一化 |

**部件清单**（`assets/master/Tails`、`assets/master/Ears`）：

- 尾 6 型：normal(母版自带) / long / fluffy / short / curl / twin
- 耳 5 型 × 左右：large / small / pointed / round / star

## 五、组装管线

`tools/run_assemble.py`：

```
make_core(coat, fur)          母版 → 按 mask 挖空 → socket 补色
  → tail（全画布直接叠加 / 锚点对齐）
  → pattern（身体层，必须在耳眼之前）
  → ear_L / ear_R
  → eye_L / eye_R
  → pupil（可选叠加）
  → clean_islands（删除 <600px 孤立碎片）
```

- **部件跟随毛色**：耳/尾原画为霜蓝，用 `recolor_coat` 随身体毛色映射（眼色不跟随，是独立性状）。
- **花纹**：alpha 遮罩用毛色 `shade` 着色，强度 0.85，clip 到身体 alpha。实测身体覆盖率：solid 0 / spots 8.9% / stripes 20.1% / gradient 34.3%（强度 0.131）/ facemark 2.1%。

## 六、客观验收（不依赖目视）

`tools/run_batch.py` 对 8 个组合的检查项：

1. **连通域 = 1**（>500px 的域只有 1 个）→ 证明无部件悬空/分离
2. **bbox 落在 60px 安全边距内** → 证明未超出画布

实测结果：8/8 全部通过，且 bbox 统一为 **(147,150)-(876,927)**，与母版完全一致。

> 说明：本阶段多次出现"视觉模型判断与数据冲突"（如判定"尾巴没挖掉""部件悬空"），最终以数值为准——挖空残留实测 0 像素、连通域实测 1。**凡涉及几何正确性，一律以脚本数值为准，目视仅用于观感评估。**

## 八、遗留问题与限制（不掩饰）

1. **包络规整抵消了极端性状的尺寸差异**：长尾/大耳变体在规整回同一包络后，外围尺寸与母版一致，差异体现为**形状与占比**而非绝对大小。若要让长尾真的更长、大耳真的更大，需改为"以身体核心为基准对齐、允许部件超出包络"——这会违反当前的包络统一规范，需要你拍板。
2. **尾巴图层在身体之上**：因 socket 不透明，尾巴无法放到 body_core 之下（会被 socket 遮住）。3/4 视角下尾巴本应在身后，当前是"尾巴在身体上层"。若需要正确的层次，尾巴区需改为透明挖空 + 尾巴在下层，代价是短尾会露洞。
3. **个别部件比例小瑕疵**：紫色星耳右耳偏大外翻、深灰个体右耳不对称——属于 AI 生成素材的个体差异，需人工修图才能彻底消除。
4. **6 个远侧肢体锚点仍未验证**（`head_center`、`shoulder_far`、`paw_front_far`、`hip_far`、`foot_hind_far`），3/4 视角下被身体遮挡，需等骨骼绑定阶段用分层 PSD 逐个确认。

## 九、下游怎么用

```python
import run_assemble as ra
img, used = ra.assemble(coat="purple", fur="short", tail="curl",
                        ear="star", eye="almond_purple",
                        pupil=None, pattern="spots")
ra.export(img, "fox_purple_curl_star")
```

- 全部素材为 1024 母版 + 512/256 导出三档，透明底。
