## 交付打包

```bash
cd tools && python make_delivery.py
```

产出到上级 `dist/` 目录，两个包均以 `Fox_Art/` 为根：

| 包 | 内容 | 体积 |
|---|---|---|
| `Fox_Art_Delivery_v1.4_<日期>.zip` | **交付包**：规范 / 数据 / 母版与导出资产 / PSD / 脚本 / 验收图 / 日志（排除 AI 原始出图 raw_s1–s3） | 约 53 MB |
| `Fox_Art_Full_v1.4_<日期>.zip` | **完整归档**：上面全部 + `09_Review/raw_s1|s2|s3` 原始出图与中间版本 | 约 76 MB |

包内根目录 `DELIVERY_MANIFEST.md` 是总清单：目录结构、资产计数、
组装/自检/重生成命令、v1.4 返修摘要、验收状态、已知边界，以及全部文件的逐条列表。
建议先读它。

## 三条不可违背的设计原则

1. **`tail_root` 与 `neck` 唯一** —— 所有尾型/头型共用同一旋转中心，一套骨骼动画复用给全部个体。这是"每只狐狸不用重做动画"的唯一保证。
2. **特殊特征一律独立素材** —— 发光、星纹、星瞳、光环绝不画进基础身体图。
3. **不为模块化强行通用** —— 不兼容就标不兼容（卷毛 × 条纹、双尾 × 短尾等），比硬凑通用件更省事。

## 能力边界（不掩饰）

可灵只出栅格 RGB 图。透明底 PNG、分层 PSD、锚点对齐的部件图，全部由**本地 Python 后处理**实现（抠图 → 去背 → 侵蚀去白边 → 锚点仿射对齐 → 合成 PSD → 下采样三档）。误差主要来自抠图边缘质量；无法干净分离的部件会改为独立重绘并在 `parts.json` 标注 `source: redraw`。
