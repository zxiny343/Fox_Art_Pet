一、v0.6 改了什么：三个机制缺陷

D1 上限实施与密度曲线不自洽 —— 95%% 的妊娠在空转

v0.5 把密度软目标顶到了硬上限（n_soft = 1.0 × N_max），于是种群到 35 只时密度曲线 L = 1 − ρ³ 仍有 0.33（鼓励受孕），但剩余名额只剩 5 < 整窝预留 6，于是被闸门拦下。实测 blocked 987–1763 次 vs 真正成窝 25–33 次。繁殖机会这么稀缺时，「谁抢到名额」是运气不是适应度，选择信号被彻底淹没。

修正：改用 L_plus_fit —— 窝仔数去适配剩余名额（越挤窝越小），只有名额连最小窝仔数都放不下才拒孕；软目标降到 0.90 × N_max，让「密度归零」与「闸门触发」对齐。

D2 幼崽存活完全不看幼崽自己的基因

v0.5 的夭折率只受母亲健康 / 食物 / 季节影响，与幼崽自身基因型无关 —— 而幼崽存活率差异恰恰是自然界选择最主要的通路。改为 Juv_sel_strength = 1.2 后，20 年近交 F 从 0.121 降到 0.099、杂合度 0.387 → 0.415。

D3 环境恒定 —— 没有方向可选

环境一成不变时，最优表型是固定的，初始种群本来就接近它，于是只剩下漂变与突变负荷在起作用（这就是 sfit 恒为负的原因）。加入 Env_light_season_amp = 22 的季节光照摆幅后，20 年近交 F 进一步降到 0.095（全档最低）。

注意：把 Selection_strength 放大到 2.0 / 3.0 反而更糟（sfit 从 −0.01 恶化到 −0.03）—— 选择差变大会让少数个体垄断繁殖、Ne 下降、漂变加剧。因此不采纳放大选择强度，保持 1.0。

三、尾数：唯一肉眼可见的进化

尾数是加性累加性状（Tn1/Tn2，1–5 尾）＋ 性选择（多尾 +3%%/尾求偶加权），20 年 1.86 → 2.38（+28%%），前 8 年就走完大部分位移，轨迹单调上升。

对照：毛长受季节交替选择（秋冬长毛有利、夏季短毛有利）→ 净选择≈0，是平衡选择，本来就不该有定向趋势（20 年 1.85→1.90，纹丝不动，符合预期）。毛色明度（右轴已除以 25 便于同图比较）只有漂移、没有方向。

四、为什么毛色进化看不见（育种家方程）

在「第 8 年换一张更亮的壁纸」场景下逐年统计：选择差 S（当上父母的个体比种群平均浅多少）切换后平均 +1.43 ± 0.40，显著为正 —— 说明自然选择确实在挑浅色个体；但 响应 R（它们的孩子比种群平均浅多少）平均 −0.32 ± 0.32，与 0 无显著差异。

原因：想要的浅色表型需要低频隐性纯合 —— 雪绒白要 ww（w 频率 0.10，出现概率约 1%%）、奶油金要 dd（d 频率 0.20，约 4%%）。有利等位绝大多数藏在杂合子里，选择看不见它们（Haldane 的经典结论）。这是当前毛色设计的固有属性，不是 bug，硬改要动 §2.1 已确认的显性序列，因此建议不改，改用尾数承载可见进化。

五、食物机制与短缺场景（F5）

把 v0.5 的「布尔开关」换成食物池 + 按适应度竞争取食：每天投递固定份数，每只的取食权重 = 自身适应度 / 种群均值，于是短缺时高适应度个体先吃饱、低适应度先掉膘。掉膘门槛 70%%，由此承载力 N* = 每日供给 / 96 —— 投喂量直接决定能养多少只。

顺带修掉的两个缺陷：① 断供时野外引入仍在每 14 天送一只狐狸进来，虚假维持了种群 —— 已改为供给满足率 < 70%% 不再有移民迁入；② 新增深度休眠保底：种群凋零到最后 3 只且全体休眠时停止衰老与疾病，保证玩家长期不投喂回来也不会发现狐狸全没了。

八、遗留问题

  • 毛色进化不可见（隐性 + 上位的固有属性）：建议不改规则，把尾数放上统计面板主位；换壁纸时给一句提示「背景变亮了，浅色毛发要十几代才看得出变化」。
  • 恒定 + 食物充足场景下选择信号仍弱（r ≈ 0.01–0.06）：靠食物档位提供压力入口，或把默认档位设成「正常」而非「充足」。
  • 单轮轨迹不可逐位复现：v0.6 重构引入的浮点路径变化会被混沌放大，对比一律用多种子均值。
  • 尾数长期会饱和到 5 尾：20 年只到 2.4，离饱和还远；饱和后由九尾（V 突变）接棒作为稀有目标。
