## 二、缺口（遗传侧有、美术侧无素材）

> 例外两项：`eye_cyan` 青瞳 = EyC，属直接映射（见第一节，2026-11-01 更正）；`tail_curl` 走 K 位点多效表达。

| 素材 | 突变池落法 |
|---|---|
| 毛色 `sakura` 樱粉 / `mint` 薄荷 / `obsidian_gold` 曜金 | A 位点新增 3 个**突变专属等位**（A^sk / A^mt / A^og）：显性级别建议 As 与 Av 之间（樱粉/薄荷偏浅色系）与 Ab 并列罕见（曜金），初始频率 0，仅突变可得；配合 dd 仍有稀释态（可用近似色或后续补图） |
| 眼色 `eye_red` / `eye_green` | Ey 位点新增 2 个突变专属等位（Ey^R 红 / Ey^G2 绿），插入显性序列末尾（低于紫），初始频率 0 |
| `ear_star` 星耳 / `pupil_star` 星瞳 | **并入 St 位点多效表达**：St 携带者同时解锁星纹 + 星耳 + 星瞳（St 本身就是稀有突变等位，与「挂突变」决定一致） |
| `pattern_gradient` 渐变 / `pattern_face_mark` 面部纹 | P 位点新增 2 个突变专属等位（P^gr 渐变 / P^fm 面纹），初始频率 0 |
| `tail_curl` 卷尾 | 不进突变池：**K=卷毛时尾巴自动切 `tail_curl`**（K 位点多效表达），无需新增位点 |
| **表情 10 种**（neutral…smug） | **不是遗传性状**，是状态件：由健康/饱食/事件驱动（§15 休眠、§16 迁徙等）。与遗传系统正交，直接用。 |

突变专属等位的共性规则：① 创始池与引入池均不出现（频率 0）；② 只能由 §8.1 突变流程产生，突变命中该位点时可落入这些等位；③ 一旦产生即正常参与遗传（可稳定传给后代）；④ 图鉴/面板中标注「突变起源」徽标。

## 四、结构性差异（两边口径不一致，需拍板）

1. **「尾型」与「尾数」是两个维度**。美术侧按形态（normal/long/fluffy/short/curl/twin），
   遗传侧 Tn1/Tn2 是**数量**（1–5）+ V 九尾。美术的 twin 恰好接住 Tn=2，
   但 3/4/5 尾没有素材（P0 缺口的根源）。
2. **毛色生产逻辑不同**。遗传侧毛色由 A（4 等位）× D（稀释）× W（上位）组合出 9 种可见色；
   美术侧是 10 个独立配色板。**建议：程序侧用「表型名 → 美术 coat id」映射表，而不是让美术侧理解基因**。
3. **姿态**：美术侧 v1.1 已从二足改为**四足**（用户拍板）。设计稿 §4 动作设计不绑定姿势，兼容；
   但 §18 面板原型里的示意 SVG 偏二足风格，集成时直接用美术素材替换。
4. **组合数口径**：美术侧文档内部有三个口径（20 万 / 108 万 / 162 万，分别漏乘不同维度），
   仅供宣传参考；遗传侧 22 位点的实际组合空间远大于此。不重要，但引用时统一用「百万级」。
